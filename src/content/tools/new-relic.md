## What is New Relic?

New Relic is an observability platform that correlates telemetry across an entire stack to identify root causes and reduce mean time to resolution (MTTR). It provides insights for both AI and traditional applications. The platform helps manage cloud-native and Kubernetes environments.

## Why use it in the API Lifecycle?

* **SRE Agent**: Automated remediation for incidents.
* **Session replay with AI**: AI identifies friction points in user sessions without manual video searching.
* **Understand cloud costs**: Real-time visibility into multi-cloud and Kubernetes spend.
* **AI and agentic monitoring**: Controls behavior and token usage across AI stacks automatically.
* **OpenTelemetry**: Supports a universal, open standard for collecting every signal.
* **Agentic Platform**: Delivers observability insights to AI agents for engineering teams.

## Best Practices

* Link application performance to customer experience and revenue.
* Identify session friction and user experience flaws with AI.
* Manage cloud-native and Kubernetes environments with infrastructure health tied to applications.
* Query logging data in place to scale logging strategies efficiently.
